Concepts
========

Begin with the concept behind the API level you are using. The four pages below
explain responsibilities and invariants; tutorials show how to build, while the
reference lists exact signatures.

When choosing a concrete object rather than learning a concept, use the
:doc:`component catalog <../reference/catalog/index>`.  It links each role back
to the relevant concept so the catalog does not become a second tutorial.
