API reference
=============

Start with the :doc:`component catalog <catalog/index>` when choosing what to
compose.  It groups the API by role—Applications, Stages, operations,
estimators, typed values and Geometry—and records inputs, outputs, domains and
stability.  Its :doc:`complete public-surface inventory
<catalog/public_surfaces>` is generated from the audited machine-readable
contract.

The remaining pages provide signature-level and subsystem reference.  They
are deliberately curated around public behavior with direct integration
evidence; internal or vendored modules are not presented as stable API.
