Evidence
========

Conformance proves a contract, regression protects observed behavior,
performance measures resource cost, and scientific evidence evaluates a
method claim. PanorAi reports these categories separately.

The complete :doc:`benchmark catalog <benchmarks>` separates runtime evidence
from accuracy and scientific claims. Its machine-readable source is
``benchmarks/catalog.json``.
The reproducible workflow is described in
:doc:`../guides/tutorials/08_benchmarking`.
