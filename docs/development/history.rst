Development history
===================

PanorAi uses Git, release notes, public contracts, and pull requests as its
complete historical archive. The checkout keeps only current operational
coordination and this compact public summary.

.. list-table:: Milestones
   :header-rows: 1
   :widths: 18 82

   * - Release / change
     - Contract and decision
   * - 3.1
     - Established ``geometry-v1`` and the 3.x compatibility boundary.
   * - 3.2–3.5
     - Added explicit feature, pose, image-processing, reconstruction, stereo,
       SLAM, and deep-learning Experimental contracts with promotion gates.
   * - 3.6
     - Consolidated consumer workflows and installed-artifact evidence without
       broad promotion.
   * - PR #193
     - Removed project-specific research artifacts from the product checkout;
       Git remains the lossless history.
   * - 3.7
     - Introduces the v2 API inventory, product-family navigation, and
       ``panorai-spatial-semantic-graph/v1`` as Experimental.

Operational claims and reports are implementation records, not product
documentation. Important decisions are promoted into contracts, release
notes, architecture, or this history before completed claims are removed.
