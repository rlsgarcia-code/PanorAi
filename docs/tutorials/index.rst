Tutorials
=========

Start with projection geometry, then move from local image evidence to
two-view and multiview geometry. Core contract snippets are included from one
executable runner and exercised in CI against the installed wheel. The visual
feature examples are reproducibly generated from a checksum-pinned public CC0
panorama; no industrial or private data is used.
