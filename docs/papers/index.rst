Methodology manuscript
======================

The current two-column manuscript specifies the training-free spherical CAM
object-hypothesis methodology and its pre-declared evaluation programme. It is
a methods paper: it intentionally contains no experimental results or
performance claim.

* :download:`Download the LaTeX source
  <spherical_cam_object_hypotheses/spherical_cam_object_hypotheses.tex>`.
* Read the executable :doc:`../tutorials/11_cam_guided_object_hypotheses`
  tutorial and :doc:`../reference/object_localization` API contract.

The source contains original TikZ diagrams for the problem definition, typed
data flow, spherical region construction, and cross-view reduction. Dataset
images, checkpoints, private panoramas, and generated experiment panels are
not part of the manuscript directory.
