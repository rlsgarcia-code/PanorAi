# Security policy

Security fixes are supported for the current 3.x release line. Experimental
APIs receive security fixes but do not receive the same signature-stability
promise as Stable surfaces.

Report a vulnerability through GitHub's private security-advisory mechanism
for `rlsgarcia-code/PanorAi`. Do not include credentials, private datasets,
embargoed details, model weights, or exploit material in a public issue.

Include the affected version, platform, minimal reproduction, impact, and
whether optional dependencies or external model acquisition are involved.
Maintainers will acknowledge the report, reproduce it in an isolated
environment, coordinate remediation, and publish an advisory when disclosure
is safe. No response-time SLA is promised by this research-led project.

Checksum verification protects external artifacts against accidental or
malicious substitution but does not grant a license or establish model safety.
